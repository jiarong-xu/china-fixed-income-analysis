# Fixed Income Research Report

[Read the full report](China_Fixed_Income_Report.md)

The report addresses three research questions:

1. What yields do the observed bond prices imply?
2. How should a conservative investor screen bond funds?
3. Why did two bonds from the same issuer show contrasting price changes?

It includes valuation formulas, price–yield curves, a credit-event timeline, possible explanations, and data references.
